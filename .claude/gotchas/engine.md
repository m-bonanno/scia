# Gotchas — the engine

For a change to `apps/server/`, `packages/core/` or `packages/contracts/`. Read with the general entries of [`.claude/gotchas.md`](../gotchas.md); each entry's story is in the issues it names.

- → One thing reached by two roads under two names is compared under both before it is added: a magnet pasted is known by its torrent's hash, one taken from the account by AllDebrid's id, and the same torrent was listed and downloaded twice (#138).
- → An entry is matched by what every entry carries, not by what one kind carries: parsing each entry of AllDebrid's infos as a file left a refusal (`{ link, error }`) unmatched, listed as a copy of another (#263). Read the key loosely first (`{ link }`), then what the entry says, in a spec that mixes kinds and orders.
- → A row that becomes another keeps what it was given: a copied folder's row of files took the setting at its Start, not the one at the copy (#263). Try a change of kind with the setting changed between the two, and with the new kind's twin already in the list.
- → One rule written in two places is a mutant that survives in each: the contract and the manager refused the same choice, and either could go (#263). The owner of the list says which places a choice may name; the contract reads its shape.
- → A format is tried in every layout its standard allows: a fragmented mp4 that kept its first samples in its movie was joined without them, with no error (#240). A layout the code does not handle is refused with a fixture of it, and so is a box too short for its fields; a header edited in place keeps its size.
- → What a download keeps beside its name while it runs — its part file, a stream's pieces, a pair's picture and sound — is reserved with the name, or a host names a finished file after it (#98, #240). The rule is one pure function (`isNameTaken`), held by a spec per suffix and per direction.
- → A wait put in front of every download is measured against a service that never answers and one that refuses: AllDebrid's public list held a direct link for 33 s with no service connected, and the E2E suite reached the real one (#49, #72, #104). One request, a short bound, a list in hand used while it is read again; every run of the real app names a simulated service.
- → A question to the system is tried for its "no" on the system it runs on: `access(folder, W_OK)` says yes on Windows for every folder that exists (#38). Prove what has to be possible by doing it: make a file, remove it.
- → A name from a host that decides something is read as the system reads it: `setup.tar.exe` and a bare `.cmd` are programs (#32). A list that is a safety rule is drawn from the system (`PATHEXT`, `assoc`/`ftype`), not from memory.
- → A size set ahead of the bytes costs nothing at the `truncate` and everything at the first write far into it: on NTFS a write at 28 GiB waited 30 s on one of Node's four disk threads, and the whole engine with it (#182). Measure a cost of the disk at the sizes people download, on the disk they use.
- → A check added at the start of a download is tried against what earlier versions left on the disk — a dense part file, another kind of file from an earlier reading — not only against what this one makes (#182, #305, #347). Try a rule about what a download holds on a new part file, a kept one made by this version, and one made by the version before.
- → An `IncomingMessage` is destroyed or drained on every path that does not read it to the end, a redirect and a refused status among them, or its socket stays busy.
- → A wait added inside a loop is tried against every timer that already watches that loop, at the largest numbers the settings allow: a connection waiting under a speed limit was cut by the idle timeout, for every read (#44).
- → A limit is paid before the read, and a read is made only against room that covers it: paid after, the last read went unlimited and the first was left owed (#44).
- → A rate is proven against a host that sends as fast as it is read, and counted in the bytes the engine took — not in bytes written, nor in the speed shown (#44).
- → A list of values is tried at both ends, and over the transport people use: at 25 MB/s, and over HTTPS, a wait that ended late gave a download a third of its limit (#44).
- → A guard taken away is searched for everything else it was guarding: the idle timer that left the socket also ended a redirect's drain and an answer nobody read (#44).
- → An address built from a host's word is parsed back before it is trusted: the URL parser makes `/f/..` into `/`, and Bunkr's home page was saved as the files (#228). Check what was built with the function that recognises it (`bunkrLinkOf(url)?.kind === 'file'`), with a spec of `.`, `..` and `''`.
- → A regular expression run over what a host or a person wrote is read for backtracking before the merge: several took seconds, one a day, on the engine's one thread (#228, #383, #388). Read by `indexOf`, or with classes that cannot pass the next delimiter, trim a trailing run with `withoutTrailing` (core), and time a hostile input in a spec, seen failing on the old expression.
- → A word from outside is not looked up in a plain object: `FAILURE_OF[code]` found `constructor` (#53). Use a `Map`, or `Object.hasOwn`.
- → A number from outside is bounded before it becomes a date, by what the contract on the other side takes: an unbounded `toISOString()` threw a 500 or wrote a year the page refuses (#53, #136, #138). Read a date on its own (`.catch(null)`): a date no calendar holds is no date, never an unreadable entry.
- → Two changes of one thing kept outside the process are made one at a time, and one given up on is undone: a vault write, a kept list of hosts and the next start's theme were each torn or left stale (#53, #65, #262). One write at a time, the last asked winning, kept only once it landed, and an answer to an older ask dropped (`lastAsked`).
- → Something the engine can do without never fails its start: the yt-dlp updater threw at every restart until Scia gave up (#100). Each step that can fail is caught and logged and the piece falls back to running without it, with a spec in which it cannot open and an E2E spec in which the app still starts.
- → A listener added to a signal that has already aborted never fires, and a shutdown hung behind it (#100). A wait checks `signal.aborted` before it listens, with a spec in which the stop comes first.
- → A simulated service written from the documentation is the documentation, not the service: the real AllDebrid answered ranges with a 204 and a first byte with a 200 (#65). Try a service for real with whoever owns the account before its "done", and see a library's behaviour in a run before a body claims it (#82, #343).
- → A program the engine starts is given an environment built from nothing and tried inside the app, not from a shell: yt-dlp got the API's token and no `TEMP` (#89). It goes through a seam a spec reads — the file, the arguments, the environment, the limit — and one that never answers is ended at the limit in a spec of its own (#182).
- → A program stopped is a tree stopped, and a fake of it in Node is not that tree: `child.kill()` ended yt-dlp's first process on Windows and its second held the output (#170). A fake that stands for a program starting others starts them `detached` on Windows, a spec waits for the second to be gone, and the program itself is tried stopped mid-read.
- → A program the engine stops at its own stop is waited for, or its leftovers outlive it in `%TEMP%` (#285, #290). Stop it before the first `await` of `close()`, keep each run's promise and `await Promise.allSettled` of them; a spec reads the folder once `close()` resolves.
- → `rm`'s `maxRetries` applies again at every level of the tree, and the retries multiply to minutes on Windows (#174). A removal that must end in time is tried again whole, within a budget the code states, timed by a spec on Windows.
- → A folder of a name known in advance in the system's temporary folder is anyone's on Linux, to make first or to swap for a link (#174, #371, CVE-2022-21658). Make a program's folder there whole with `mkdtemp`, and check what a start clears before removing it — a directory, not a link, this account's own; lint refuses `join(tmpdir(), '<literal>')`.
